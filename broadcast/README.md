# Безкоштовний автоматичний ефір DJ_SKY_STYLE RADIO

Ця папка створена для тарифу **Caster.fm Free Cloud**. У ньому немає серверного AutoDJ, але цей запускатор безкоштовно передає вашу музичну чергу у Caster.fm самостійно, без ручного перемикання треків.

> Важливо: комп'ютер має залишатися увімкненим, підключеним до інтернету та не переходити в сон. Якщо вимкнути комп'ютер, безкоштовний ефір зупиниться. Повністю автономний 24/7 AutoDJ на сервері є лише в Caster.fm Pro або іншому платному хостингу.

## Підготовка — один раз

1. Встановіть **FFmpeg**. Найпростіше: відкрийте Windows Terminal або PowerShell від свого імені та виконайте:

   ```powershell
   winget install Gyan.FFmpeg
   ```

   Після інсталяції закрийте й знову відкрийте вікно PowerShell.

2. Відкрийте `D:\RADIO\broadcast`.
3. Скопіюйте файл `caster.config.example.json` і назвіть копію точно `caster.config.json`.
4. Відкрийте `caster.config.json` у Блокноті. Поля `host`, `port`, `mountPoint` та `username` уже заповнені для вашого Caster.fm-каналу. У поле `password` вставте **пароль трансляції** з панелі Caster.fm.
5. Відкрийте у браузері вашу папку Google Drive. Завантажуйте у `D:\RADIO\broadcast\music` **MP3-файли**. WAV не використовуйте: вони у кілька разів більші, але для ефіру 96 Кбіт/с не дадуть помітно кращого звучання.
6. Двічі клацніть `Запустити-радіо.cmd`.

Коли вікно покаже повідомлення `Починаємо чергу`, музика вже передається на Caster.fm. На сайті відкрийте сторінку радіо та перевірте плеєр.

## Як це працює

- Усі MP3, M4A, AAC, OGG, WAV з `broadcast\music` потрапляють у чергу.
- Черга перемішується, кожен трек грає до кінця, потім автоматично запускається наступний.
- Після останнього треку запускається нова перемішана черга.
- Після короткого збою інтернету запускатор пробує під'єднатися знову через 5 секунд.
- Для зупинки ефіру натисніть `Ctrl + C` у вікні запускатора.

## Безпека

`caster.config.json` і музичні файли навмисно не публікуються в GitHub, Vercel або на сайті. Не надсилайте цей файл нікому: у ньому міститься пароль трансляції.

## Автозапуск після перезавантаження — за бажанням

Щоб ефір стартував після входу у Windows, створіть ярлик для `Запустити-радіо.cmd` і перемістіть цей ярлик у папку автозавантаження Windows. Це необов'язково: спершу перевірте, що ручний запуск працює стабільно.
