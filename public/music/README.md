# Музична база DJ_SKY_STYLE RADIO

Ця папка призначена для MP3-файлів, які відтворює сторінка `/music`.

Початкові назви файлів:

- `dj-sky-night-01.mp3`
- `dj-sky-night-02.mp3`
- `dj-sky-night-03.mp3`
- `dj-sky-night-04.mp3`

Використовуйте лише власну або належно ліцензовану музику. Дані треків змінюються у `data/music-library.ts`.
