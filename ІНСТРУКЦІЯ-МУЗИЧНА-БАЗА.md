# Музична база та автоматичне відтворення

## Що вже реалізовано

Сторінка `/music` містить музичну чергу. Після того як слухач натисне **«Запустити базу»**, сайт автоматично переходить до наступного треку після завершення попереднього.

Браузери не дозволяють самостійно вмикати звук під час відкриття сторінки. Це захист користувача, тому перший клік завжди необхідний. Після нього черга працює автоматично.

## Як додати треки на сайт

1. Підготуйте лише власні або ліцензовані MP3-файли.
2. Відкрийте папку `D:\RADIO\public\music`.
3. Додайте файли з назвами:
   - `dj-sky-night-01.mp3`
   - `dj-sky-night-02.mp3`
   - `dj-sky-night-03.mp3`
   - `dj-sky-night-04.mp3`
4. Відкрийте `D:\RADIO\data\music-library.ts` і для кожного рядка змініть `title`, `artist`, `genre` та, якщо треба, `source`.
5. Для перевірки відкрийте PowerShell у `D:\RADIO` і виконайте:

   ```powershell
   npm.cmd run dev
   ```

6. Відкрийте `http://localhost:3000/music` і натисніть **«Запустити базу»**.
7. Після перевірки опублікуйте файли:

   ```powershell
   git add public/music data/music-library.ts
   git commit -m "Додано музику до бази"
   git push origin main
   ```

Vercel автоматично оновить сайт.

## Як зробити справжній ефір 24/7

Сторінка сайту грає музику лише для конкретного відкритого браузера. Щоб радіо грало незалежно від телефону або комп’ютера DJ, музична черга повинна працювати на сервері трансляції.

1. Увійдіть до Caster.fm Cloud.
2. Відкрийте канал **DJ_SKY_STYLE RADIO**.
3. Знайдіть розділ **AutoDJ**, **Media Library** або **Playlist**.
4. Якщо цей розділ є у вашому тарифі, завантажте туди лише ліцензовану музику, створіть плейлист і ввімкніть AutoDJ.
5. Не змінюйте mount point, пароль трансляції чи інші серверні дані на сайті.
6. Після старту AutoDJ сайт автоматично покаже поточний трек у блоці «Зараз звучить» та в історії.

Якщо в панелі Caster.fm немає AutoDJ/Media Library, це обмеження тарифу. Тоді для безперервного серверного ефіру потрібен тариф із AutoDJ або окремий сервер трансляції; сайт сам по собі не може бути сервером радіо.
